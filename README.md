# VirusTotalFolderScanner
Приложение на Python для сканирования папок на вирусы через VirusTotal API. Нужен API-Key из профиля VirusTotal. Выберите папку и запустите анализ! A Python app to scan folders for malware via VirusTotal API. Requires an API Key from your VirusTotal profile. Just select a folder and start scanning!
